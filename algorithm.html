점수 구성 실험실

앱의 새 노출 부담 산식을 설명하고 저장 영역 값으로 가상 평균을 실험합니다. 이 공개 페이지는 합성 예시만 사용합니다. 편집기 수치는 앱의 새 누적 점수가 아니며 의료적 판단도 아닙니다.

현재 앱의 계산 방식

0.10도 사용자가 고른 비중인 화면 26% · 환경 22% · 자세 8% · 사용 18% · 눈 26%를 유지합니다. 상관된 화면·눈 단서는 중복 합산하거나 정상 단서와 단순 평균하지 않습니다. 어둠·상대 화면 밝기와 화면 변화가 동시에 관측되면 분당 부담률에 최대 8%p의 교호작용을 더합니다.

분당 부담률 = Σ(영역 비중 × 관측 영역 부담) + 어두움×화면 변화 교호작용(≤8%p)
누적 부담 = ∫ 분당 부담률 × 실제 관측 활성 시간
표시값 = 100 × (1 − exp(−누적 부담분 / 40))

40 부담분 척도, 위험 구간, 교호작용 상한은 연구에서 직접 검증된 값이 아닌 제품 가설입니다. 품질·결측은 부담을 0으로 낮추는 배수가 아니라 별도 표시입니다. 0.10의 서버 집계에는 앱 내부 누적분과 교호작용 전 과정이 없으므로 아래 편집기로 저장 점수를 복원할 수 없습니다. 0.7 이전은 품질 가중 평균 방식의 역사적 버전입니다.

조도는 실측 lux, 밝기 설정은 상대 제어값이며 화면 휘도나 망막 노출량이 아닙니다. 가까운 거리는 카메라축 추정이고 유효 관측이 있을 때만 같은 사용 영역 안에 반영합니다. 게임 이름이나 사용자가 고른 콘텐츠 종류에 독립 가산점을 주지 않습니다.

연구 근거와 한계

30분 휴대전화 읽기 실험에서는 어두운 방과 밝은 화면의 조합에서 눈물막·깜박임·피로 변화가 크게 관찰되었습니다. 20분 읽기 실험에서는 눈물막 안정성 변화가 관찰되었습니다. 읽기 연구 결과를 게임 사용의 개인별 피로값으로 바로 바꿀 수는 없습니다.
