# EyeCare 0.1.0-alpha 검증 기록

검증일: 2026-10-08. Windows 로컬 빌드와 Android 15 AOSP 에뮬레이터에서 확인했습니다. 실제 휴대폰 검증은 아직 수행하지 않았습니다.

## 전달물

- `artifacts/eyecare-0.1.0-alpha-debug.apk`: Android 10 이상에서 설치할 수 있도록 빌드한 debug 서명 APK. 실제 실행 검증 버전은 Android 15입니다.
- `artifacts/eyecare-0.1.0-alpha-debug.apk.sha256`: 전달 APK의 SHA-256.
- `artifacts/screenshots/`: 에뮬레이터에서 촬영한 실제 앱 화면. 디자인 목업이 아닙니다.
- `artifacts/verification/`: 단위 테스트 XML, 통합 테스트 결과, 린트 및 APK 검증 결과.

### Android 통합 시나리오

1. 시스템 화면 공유 동의를 취소하면 분석 세션이 시작되지 않음.
2. 명시적으로 전체 화면 공유를 승인하고 별도의 테스트 앱을 실행. 해당 앱의 색상 변화가 실제 MediaProjection 프레임으로 입력되어 유효 분석 시간과 변화가 큰 구간을 생성함. 회전 후 분석 지속, 사용자 종료, 기록 열기, 불편감 응답 저장까지 확인.
3. 화면을 끄면 분석이 종료되고 기록이 저장됨. Android 버전에 따라 앱 또는 시스템이 먼저 중단할 수 있어 종료 사유는 `screen_off` 또는 `system_stopped`를 허용.
4. 독립적인 테스트 DB에 저장 후 다시 열어 요약·구간·불편감 응답을 복원하고 삭제할 수 있음.

테스트 색상 화면은 테스트 APK에만 들어 있습니다. 전달 앱에는 포함하지 않았습니다. 화면 캡처 파일 생성도 테스트 코드에만 있으며, 실제 앱의 분석 경로에서는 이미지를 저장하지 않습니다.

## 엔진 결과를 해석하는 범위

- 초당 최대 2회의 작은 화면 표본에서 디지털 밝기 변화량을 계산합니다. 물리적 화면 밝기, 고주파 점멸, OLED PWM, 실제 시선 또는 임상적 눈 피로를 측정하지 않습니다.
- 변화가 큰 구간은 평균 절대 밝기 변화 0.10 이상이고, 0.15 이상 변한 픽셀이 25% 이상인 표본 간 구간입니다. 이 기준은 초기 공학적 기준이며 개인별 피로 경계값이 아닙니다.
- 표본 간격이 1.5초보다 길면 시간을 채우지 않습니다. 아주 어두운 화면이나 보호 콘텐츠처럼 검게 입력되는 화면도 분석에서 제외합니다. DRM 여부를 확정적으로 식별하는 기능은 없습니다.
- 그래프는 해당 세션 내부의 상대 변화입니다. 서로 다른 세션에서 같은 막대 높이가 같은 절대 변화량을 의미하지 않습니다.
- 현재 휴식 알림은 분석 시작 후 25분의 시간 기준입니다. 화면 변화량에 따라 휴식 시점을 개인화하는 모델은 아직 구현하지 않았습니다.
- 최대 30분 분석 후 자동 종료합니다. 이번 알림 끄기는 현재 세션에만 적용됩니다. 분석 종료 후 상시 추적·재알림은 없습니다.

## 후속 개발 순서

1. **실기기 파일럿:** 현재 APK를 실제 영상·게임에 적용해 커버리지와 배터리를 측정하고, 시작·종료·기록 확인 흐름의 불편을 수정합니다.
2. **화면 엔진 보정:** 장면 전환·스크롤·전체 화면 변화·어두운 화면의 기준 데이터를 만들고 기기별 비교 가능성을 확인합니다. 고주파 점멸 연구는 현재 2fps 엔진과 별도로 설계해야 합니다.
3. **전후 30~60초 눈 상태 확인:** 전면 카메라를 켠 명시적 검사 세션에서 얼굴·눈 가시성, 깜박임, 신호 품질을 측정합니다. 기존 NeuroLens에서 검증 가능한 품질 관리 접근과 필요한 특징만 선택적으로 옮깁니다.
4. **케어 연결 검증:** 콘텐츠 특징·노출 구간·자가 보고·전후 검사 사이의 관계를 수집하고, 설명 가능한 휴식 제안을 검증합니다. 검증 전에는 임의의 종합 피로 점수를 출시하지 않습니다.

## 재실행

```powershell
.\build.ps1
```

기기 또는 에뮬레이터가 연결되어 있다면:

```powershell
.\build.ps1 -Tasks @('connectedDebugAndroidTest')
```

UI 테스트는 Android 15 AOSP의 영어 시스템 화면 공유 대화상자와 한국어 앱 UI를 대상으로 작성했습니다. 다른 시스템 언어·제조사에서는 선택자 조정이 필요할 수 있습니다. UI 테스트는 테스트 기기에서 화면 공유를 승인하고 회전·화면 꺼짐을 실행합니다.
