# 0.12.1-alpha: 전체 연구 데이터 내보내기

## 변경 내용

- 설정 화면 맨 아래에 **연구 데이터 내보내기** 카드를 추가했습니다. 버튼은 세 개입니다.
  - `CSV 저장`: 한 줄에 리포트 하나가 들어가는 분석용 파일입니다.
  - `JSON 저장`: 전체 원본 파일입니다.
  - `두 파일 함께 공유`: 메일이나 드라이브 등으로 두 파일을 함께 보냅니다.
- 내보내는 대상은 이 폰에 저장된 **모든** 리포트입니다. 500건씩 나눠 읽기 때문에 1,000건 제한이 없습니다.
- CSV 열 구성
  - 식별·시간: 리포트·세션 ID, 생성 시각과 집계 시작 시각(ISO-8601, 기기 시간대), 산식 버전
  - 점수: `burden_score`(저장 부담 점수), `condition_score`(화면 표시 눈 컨디션 = 100 − 부담), `comparable`, 신뢰도, 가용 비중, 기본 점수, 교호작용률, 오늘 누적 부담과 관측 분
  - 관측 품질: 화면 coverage, 눈 검출률, 카메라 fps
  - 피로 응답: NRS 첫 응답과 최신 응답(각각 시각 포함), 응답 수. 0.7.3 이전 방식으로 리포트에 붙어 있던 응답도 포함합니다.
  - 영역: 5개 영역 각각의 부담률, 품질, 기여
  - 신호: 모든 신호 ID(F02.blinksPerMin 등)의 값, 품질, 결측 사유
- CSV는 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM을 붙입니다. 빈칸은 측정되지 않았다는 뜻이며 0을 채우지 않습니다.
- JSON(`neurolens-eyecare-research-dataset` v1)에는 모든 세션, 리포트(`CareReportCodec` 원형 그대로), NRS 응답 이력(수정 체인 포함), 이벤트가 들어갑니다.
- 파일은 앱 캐시에만 만들어지고, 사용자가 저장하거나 공유할 때만 폰 밖으로 나갑니다. 자동 업로드는 없습니다. 화면 이미지와 얼굴 영상은 원래 저장하지 않으므로 포함되지 않습니다.

## 웹 대시보드 (xshoner/eyecare, 로컬 커밋 8fac290, 미게시)

- '최근 관측' 카드에 `관측 CSV 다운로드`와 `피로 응답 CSV 다운로드` 버튼을 추가했습니다.
- 관측 CSV에는 연결된 브라우저가 읽을 수 있는 전체 관측이 저장된 열 그대로 들어갑니다. 여기에 `condition_score`, `comparable`, `synthetic`, NRS 요약 열을 더합니다.
- 피로 응답 CSV에는 수정 이력을 포함한 모든 응답이 들어갑니다.
- 파일은 브라우저 안에서 만들어지며 서버로 전송하는 것은 없습니다.
