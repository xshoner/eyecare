# EyeCare 눈 피로 측정 자체 벤치마크 프로토콜

초안 v0.1 · 2026-10-10 · 연구 시작 전에 대상·도구·수치·분할·분석을 확정하고 버전을 고정한다.

벤치마크는 **영상에서 눈과 맥박을 제대로 측정하는가**, **같은 상태를 반복 측정할 수 있는가**, **측정값으로 눈 피로를 추정할 수 있는가**를 각각 평가한다. 하나의 합성 시험이나 소수 세션으로 세 단계를 동시에 승인하지 않는다.

## 1 평가 대상

| 평가 단계 | 입력 | 기준 | 결과 |
|---|---|---|---|
| L0 기존 화면 회귀 | 기존 특징 입력·기록, 알려진 디지털 화면 | 기존 엔진 출력·시간 합계 | 기존 앱 기능 보존 |
| L1 눈·시선·rPPG 정확도 | 표준 검사 영상·실측 시간 | 수동 눈 라벨·과제 좌표·센서 | 특징별 정확도와 보류율 |
| L2 반복성·강건성 | 같은 사람의 반복 검사, 조명·자세·기기 변화 | 동일 상태 반복 및 조건 기록 | 측정 잡음과 개인 기준선 |
| L3 피로 추정 | 검사 특징·화면 특징·과거 응답 | 미리 정의한 현재 응답 | 독립 사람·미래 시점의 추정 오차 |
| L4 실제 앱 | 자연 콘텐츠와 부분 관측 | 실제 종료 응답·중단·전력 로그 | 실환경 성능·실패·부담 |

웹캠 눈깜빡임 연구와 시선 과제를 참조하되 자체 스마트폰 조건으로 평가한다. [참조 검토](REFERENCE_AUDIT.md)

## 2 기준 신호 확보

### 눈 이벤트

연구 동의를 받은 원본 눈 ROI와 프레임 시각을 보관한다. 가능하면 실제 처리 입력과 같은 60fps 영상으로 라벨을 만든다. 폰이 30fps만 제공하면 해당 영상에서 확인할 수 있는 사건과 시간 오차를 구분한다. 정밀 지속시간·불완전 깜빡임 검증은 별도 60~120fps 연구 카메라를 사용할 수 있다.

2명의 라벨러가 무작위 순서의 클립을 독립적으로 표시한다. 피로 응답과 알고리즘 결과를 보지 않는다. 불일치는 합의 또는 제3 검토로 정리하며, 라벨러 일치도와 수정 이력을 남긴다.

| 라벨 | 정의 |
|---|---|
| visible_open | 눈꺼풀·안구가 충분히 보여 개방도를 판독할 수 있음 |
| blink_complete | 눈감기·다시 열기가 관측되며 완전 감김 기준을 영상에서 확인 |
| blink_incomplete | 눈감기·다시 열기는 관측되지만 완전 감김이 확인되지 않음 |
| closure_long | 길게 닫힌 구간. 경계 길이는 개발 라벨 분포에서 고정 |
| partial_lid_closure | 깜빡임 외 구간에서 지속적으로 개방도가 낮음 |
| intentional_closure | 지시나 참가자 기록으로 확인된 의도적 눈감기 |
| gaze_down/squint | 아래 보기·찡그림의 관측/과제 조건 |
| occluded/unknown | 안경 반사·손·눈 ROI 이탈·해상도 부족으로 판독 불가 |
| event_censored | 시작·끝·중간의 일부가 관측되지 않아 완결 여부 불명 |

완전 감김을 판독할 수 없는 영상을 불완전 깜빡임 정답으로 만들지 않는다. 판독 불가 비율도 성능 결과에 포함한다. 양 눈 각각과 양안 이벤트를 구별한다. 자연 보기 중 의도적 눈감기는 피로의 양성 정답으로 사용하지 않는다.

눈 검출 파일럿은 최소 12명에서 300개 이상의 판독 가능한 자연 깜빡임 이벤트를 목표로 한다. 긴 감김·불완전 깜빡임의 사례가 부족하면 해당 특징을 승인하지 않고 추가 모집한다. 검출기 동작 확인용 지시 눈감기·짧은 가림은 별도 세트로 남긴다.

### 시선

참조 렌더러의 목표 위치·이동 궤적·실제 표시 시각을 기록한다. 보정점과 평가점은 다르게 배치한다. 지시를 따르지 않은 경우도 기록하고, 참가자의 실제 응시를 목표 위치와 동일한 정답으로 가정하지 않는다.

목표 위치 비교는 목표 대용 평가다. 기준 시선 장비가 있으면 일부 연구에서 동시에 기록해 실제 주시점·이벤트 비교를 수행한다. 장비가 없으면 각도 단위의 정확도나 미세 사카드 성능을 승인하지 않는다.

### rPPG

동기화할 수 있는 접촉 PPG 또는 ECG를 기준으로 사용한다. HR 숫자만 주는 장비는 HR 비교에 한정한다. 박동 시각·HRV/PRV 검증에는 원시 파형 또는 검증된 박동 시각이 필요하다.

기준 센서 자체의 품질·빠진 구간·시계 정보도 보관한다. 수신 시각과 실제 표본 시각을 구별하고 시작·중간·끝의 정렬 오차를 확인한다. 스마트폰 손가락 PPG나 다른 rPPG 알고리즘은 독립적인 확정 정답으로 간주하지 않는다.

기준 센서를 확보하기 전에는 공개 데이터의 연구 조건과 합성 회귀로 알고리즘 오류를 찾는다. 실제 폰 HR 정확도는 미승인 상태로 둔다.

## 3 피로 응답과 혼동 요인

주 목표 질문은 **“지금 눈이 얼마나 피곤한가요?”**, 0=전혀 피곤하지 않음, 10=매우 피곤함이다. 문구·척도·앵커·언어 버전을 고정한다. 즉시 응답의 반복성과 이해도를 파일럿에서 확인한다.

건조/따가움, 흐림, 졸림, 전반적 피곤함은 별도 질문으로 수집한다. 졸림과 눈 피로의 높은 동반 여부를 분석한다. 눈 감김을 그대로 피로 정답에 넣거나, 깜빡임이 적다는 이유로 피로 응답을 수정하지 않는다.

수면·카페인·최근 운동·콘택트렌즈·안경·알려진 눈 증상·복용 관련 맥락·시간대·콘텐츠 과제·조명·거리·폰 자세를 기록한다. 전부 모델에 넣기보다 사전 정한 최소 보정 변수와 층화 분석에 사용한다. 불필요한 개인 식별정보는 수집하지 않는다.

CVS-Q 등 검증 설문은 언어·사용 조건·회상 기간을 확인한 뒤 연구 방문 또는 장기 결과에 사용한다. 0~10 순간 응답과 같은 정답으로 섞지 않는다. [CVS-Q 원 연구](https://pubmed.ncbi.nlm.nih.gov/25744132/)

응답은 예정 시각과 실제 시각을 모두 기록한다. 종료 직후 응답은 60초 이내를 첫 운영 목표로 삼고 지연·건너뛰기·시계 불일치를 분리한다. 60초는 연구 운영 값이며 건강 기준이 아니다.

## 4 표준 과제와 방문

### 표준 검사

`품질 확인 10초 → 자연 보기 60초 → 고정 응시 15초 → 부드러운 추적 15초`

첫 방문에 보정·독립 검증 약 60초를 추가한다. 화면·목표·순서·지시·평균 색·밝기 버전은 고정한다. 자연 보기에는 “깜빡이지 마세요” 같은 지시를 사용하지 않는다. 얼굴 미리보기는 정렬 후 최소화해 자연 깜빡임에 미치는 영향을 줄인다.

### 방문 구조

1. 동의와 환경 확인, 초기 상태 기록.
2. 일상적인 무화면 휴식 약 5분 후 초기 응답과 PRE 검사. 응답이 0이라고 가정하지 않는다.
3. 배정한 일상적 화면 과제 약 20분. 기존 최대 30분 제한 안에서 수행한다.
4. 종료 직후 응답, POST 검사. 콘텐츠 종료부터 검사까지의 간격 기록.
5. 선택한 휴식 약 5분 후 응답·RECOVERY 검사. 중단 요청은 즉시 처리한다.

구체적 휴식·노출 길이는 파일럿과 연구 검토 후 확정한다. 불편을 참도록 강요하지 않고 심한 증상이 있으면 종료한다. 건강 관련 인간 대상 연구의 동의·윤리 검토 적용 여부를 연구 시작 전에 확인한다. [Google Play 연구 앱 관련 정책](https://support.google.com/googleplay/android-developer/answer/16679511?hl=en)

### 비교 조건

| 조건 | 목적 | 통제 |
|---|---|---|
| 무부하 반복 | 검사만으로 생기는 변동·연습 효과 | 검사 간 동일 간격, 동일 밝기·자세 |
| 낮은 변화 영상 | 일반적 시청의 기준 | 길이·평균 밝기·음량·흥미 기록 |
| 변화가 큰 일상 영상 | 화면 신호와 반응 관계 | 위험한 점멸 생성 없이 정상 콘텐츠 사용 |
| 읽기·게임 | 과제·집중도에 따른 일반화 | 별도 과제층. 영상과 단순 인과 비교하지 않음 |
| 자연 쇼츠 | 실제 사용 조건 확인 | 실제 유효 관측·중단·앱 전환·폰 움직임 기록 |

조건은 가능한 범위에서 방문별 무작위 순서로 배정한다. 같은 날 연속 과제의 잔여 영향은 피하고, 방문 간 초기 응답·시간대를 비교한다. 짧은 검사만으로 충분한 피로 차이가 생기지 않으면 자료를 그대로 보고하고 자연 사용 기록을 추가한다. 피로 차이를 만들기 위해 자극을 무리하게 높이지 않는다.

## 5 표본과 분할

| 단계 | 계획 규모 | 목적 |
|---|---|---|
| 기술·라벨 파일럿 | 성인 12명, 대표 폰 3종 이상 | 카메라·라벨·동기화·눈 이벤트·HR 실패 발견 |
| 반복성 파일럿 | 성인 30명, 가능하면 3방문 | 무부하 잡음, 전후 관측 범위, 응답 분포·누락 |
| 모델 평가 연구 | 초기 계획 성인 120명, 2방문 이상 | 훈련 60명·검증 20명·새 잠금 시험 40명 |
| 외부·기기 평가 | 별도 성인 20명 이상, 학습에 없는 기기 포함 | 다른 조건의 일반화. 부족한 조건은 미승인 |

이는 모집 계획이며 충분한 검정력을 보장하는 계산이 아니다. 30명 파일럿의 변동·응답 분포·효과 크기를 바탕으로 통계 담당자가 공식 표본 수를 확정한다. 잠금 시험이 너무 작거나 상태 분포가 좁으면 점수 출시 결정을 미룬다.

참가자 1명에게서 얻은 모든 영상·창·방문은 같은 분할에 둔다. 겹치는 창을 서로 다른 분할로 나누지 않는다. 기존 개인 테스트 4개 세션은 회귀 자료이며 독립 모델 시험 인원으로 세지 않는다.

개인화는 별도 평가다. 개인의 과거 방문으로 기준선을 만들고 이후 방문만 예측한다. 집단 모델 평가용 새 참가자의 POST 데이터가 개인 기준선에 미리 섞이지 않게 한다.

주요 층은 제조사·카메라, 피부톤, 안경/렌즈, 조명, 폰 방향·거리·머리 자세, 응답 상태다. 모든 조합을 적은 표본으로 검증했다고 말하지 않는다. 참가자 수·관측 범위·보류율을 층별로 보고하고 자료가 부족한 층은 별도 표시한다.

## 6 잠정 통과 기준

아래는 구현 품질을 판단하기 위한 **초기 공학 목표**다. 측정 결과나 의학적 경계가 아니다. 개발 자료로 조정한 뒤 잠금 시험을 열기 전에 고정한다. 시험을 본 뒤 수치를 바꾸면 새 시험 모집이 필요하다.

| 대상 | 지표 | 초기 목표 |
|---|---|---|
| 기존 화면 | 동일 입력·기존 보고서 재계산 | 기존 수치·시간 보존, 버전과 원본 의미 유지 |
| 자연 깜빡임 | 이벤트 precision·recall·F1 | F1 ≥0.90, precision/recall 각각 ≥0.85 |
| 이벤트 대응 | 단일 이벤트의 시작 매칭 | ±100ms 이내 1:1 매칭, 중복 검출은 FP |
| 깜빡임 기간 | 고율 기준 대비 MAE | ≤50ms 목표, 프레임율·누락별 별도 보고 |
| 긴 감김 | 이벤트 F1·시간 오차 | F1 ≥0.90, 눈 감김을 품질 불량으로 제외한 비율 별도 |
| 불완전 깜빡임 | 수동 판독 가능 사례의 F1 | ≥0.80 및 전체 판독/출력 범위 보고. 미달이면 후보로만 보관 |
| 개방도·폐쇄 비율 | 수동 영상 대비 오차 | 폐쇄 시간 비율 MAE ≤5%p 목표, 하방 시선·찡그림 오류 별도 |
| 시선 목표 대용 | 중앙·p95 위치 오차 | 화면 긴 변 기준 중앙 ≤8%, p95 ≤15% |
| 시선 구역 | 독립 목표 구역 macro-F1 | ≥0.80, 구역별 혼동 행렬 |
| rPPG HR | 기준 장비와 같은 10초 epoch | MAE ≤5bpm, p95 절대 오차 ≤10bpm, 자연 보기 출력 범위 ≥70% 목표 |
| 광학 음성 대조 | 맥박 없는 합성/재생·광학 잡음 채택 | 허위 ‘유효 맥박’ ≤5% 목표. 실제 음성 실험과 합성 결과를 구별 |
| 반복성 | 무부하 같은 조건 전후 | 피로 변화와 구별할 오차·95% 일치 한계 제시. 잡음보다 작은 변화는 미검출 처리 |
| 피로 NRS | 새로운 참가자의 현재 응답 MAE | ≤1.5/10 목표, M4가 M1보다 상대 MAE 15% 이상 개선하는지 평가 |
| 추가 신호 | M4와 각 신호 제거 모델 | 사람 단위 bootstrap에서 개선 차이의 95% CI 보고. 기여가 불명확하면 연구 상태 유지 |
| 모델 출력 범위 | 전체 적격 검사 중 결과 제공 비율 | ≥70% 초기 목표, 같은 출력 범위의 모델 비교도 함께 수행 |
| 모바일 자원 | 참조 검사·동시 분석 상대 소비 | 실제 기기 측정으로 예산 확정, 열 한계·메모리 누적·프레임 지연은 출시 차단 사유 |

30fps에서 정확한 빠른 동작 기간을 충분히 분해할 수 없는 경우 기간 출력과 그 통과 기준을 제한한다. F1이 높은 것과 지속시간이 정확한 것은 별개다.

## 7 분석 방법

눈 이벤트는 이벤트 대응과 유효 시간 마스크를 고정해 평가한다. 검출 누락 때문에 긴 감김을 지운 시간을 포함해 품질 처리 오류를 따로 계산한다. 라벨러 일치도와 판독 불가율을 함께 제시한다.

rPPG는 비중첩 기준 epoch에서 HR 오차·편향·일치 한계와 출력 범위를 계산한다. 겹치는 분석 창은 출력 안정화에 사용할 수 있지만 독립 표본 수로 세지 않는다. 추세 보정으로 생긴 값은 관측 HR와 별도다. HRV/PRV는 기준 박동과 대응한 간격 오차·누락/추가 박동을 별도 평가한다.

피로 주 지표는 참가자 단위 MAE다. 참가자 안의 여러 방문·창을 독립 사람처럼 세지 않는다. RMSE·보정도·상태별 오차·전후 변화 방향도 보고한다. 심한/가벼운 상태를 나눌 경우 경계와 지표를 사전에 추가하고 유리한 경계를 사후 선택하지 않는다.

모델 후보의 특징 선택·정규화·결측 처리·하이퍼파라미터는 훈련/검증 내부에서 완료한다. 잠금 시험은 최종 후보에 한 번 사용한다. 자기보고 중 예측 대상 응답은 모델 입력에서 제외한다. 이미 열어 본 시험 자료는 회귀 자료로 승격하고 새 자료를 확보한다.

M0→M4 단계별 비교와 각 신호를 제거한 비교를 시행한다. rPPG의 정확성과 눈 피로 추정에 대한 추가 기여를 구별한다. 졸림·정신적 부하만 예측하는 모델이 아닌지 혼동 요인별 평가를 시행한다.

## 8 동시 측정과 음성 대조

동시 측정에는 정상 영상·쇼츠 넘김·정지·앱 전환·회전·잠금·카메라를 쓰는 다른 앱·조명 변화·폰 움직임을 포함한다. 사용자는 실제 공유 범위를 기록한다. 화면과 카메라의 유효 범위가 겹치는 시간만 반응 연결에 사용한다.

표준 중립 화면, 밝기 변화, 색 변화, 머리 움직임, 얼굴 일부 가림, 합성 RGB 무맥박을 따로 재생한다. 화면의 광학 변화가 실제 기준 심박과 다른데도 맥박으로 채택되는지 평가한다. 배경색의 주기적 변화가 맥박과 우연히 비슷한 경우도 포함한다.

기존 2fps 화면 특징으로 고주파 광학 잡음이 제거됐다고 판정하지 않는다. 강한 간섭에서는 rPPG 보류가 정확도 높은 듯한 오출력보다 바람직한 결과다. 보류율이 너무 높으면 해당 동시 측정 모드의 활용 범위를 축소하고 표준 검사로 측정한다.

## 9 연구 자료와 결과 패키지

연구 자료는 participant pseudonym, 방문·검사·노출 ID, 동의 범위, 과제·카메라·알고리즘 버전, 원본 해시, 라벨 버전, 분할, 품질·응답 시각을 연결한다. 모델마다 사용한 데이터 snapshot과 입력 계약·훈련 설정·잠금 시험 열람 이력을 남긴다.

각 벤치마크 결과는 다음 자료로 구성한다.

- 조건별 참가자·기기·이벤트·관측 시간과 제외 이유.
- 수동 라벨·기준 센서 품질과 정렬 오차.
- 센서 정확도·오차 분포·출력 범위·음성 대조 결과.
- 무부하 반복성·실제 사용의 실패 사례.
- M0~M4 성능, 보정도, 참가자 단위 CI, 신호 제거 비교.
- 모델 카드, 지원 조건, 점수 보류 조건, 전력·발열 결과.

임계값·프로토콜·평가 코드가 바뀌면 새 버전으로 기록한다. 연구 참여 철회 시 해당 자료와 파생 snapshot의 사용 여부를 확인한다. 제품 영상과 연구 원본을 구별하고 연구 원본에는 제한된 접근과 목적에 맞는 보관 기간을 적용한다.
