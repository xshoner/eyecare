# 0.15.0-alpha: 시간 가중 감점, 웹 대시보드 인식, 하단 표기

전체 정의는 [DEDUCTION_MODEL_0.15.md](DEDUCTION_MODEL_0.15.md)에 있습니다.

## 변경 내용

- **점수 산식 `efs-deduction-0.15`** (0.14보다 엄격)
  - 화면 시청: 연속 시청 0–20분 분당 0.05, 20–40분 0.10, 40–60분 0.20, 60–90분 0.40, 90분 이후 0.90
  - 쉬지 않고 오래 보기: 20–40분 0.15, 40–60분 0.30, 60–90분 0.50, 90분 이후 0.80
  - 가까이 보기: 가까운 상태 20분까지 ×1, 이후 60분까지 최대 ×4
  - 어두운 곳: 60분에 ×4 (0.14는 40분 ×3이 최대)
  - 번쩍이는 화면·깜빡임 감소·찡그림·누워서 보기: 연속 시청 20분 이후 60분까지 최대 ×2
  - 어두운 곳+가까이+오래 겹침 배수(×1.6)는 연속 20분부터 적용, 감점 상한은 분당 4점
- **웹 대시보드**: `efs-deduction-0.14`·`0.15`를 비교 가능한 산식으로 인식합니다. 표에 눈 컨디션(100 − 점수)과 5단계를 표시합니다.
- **앱 하단 표기**: 모든 화면 맨 아래에 "© 2026 · Powered by AXopenlab"를 넣었습니다.
- 이전 0.14 보고서는 점수·버전을 바꾸지 않고, 앱과 웹 모두 감점 모델로 인식합니다. 추이는 같은 버전끼리만 비교합니다.
