# 0.14.0-alpha: 감점 모델과 위험도별 알림

전체 정의는 [DEDUCTION_MODEL_0.14.md](DEDUCTION_MODEL_0.14.md)에 있습니다.

## 변경 내용

- **새 점수 산식 `efs-deduction-0.14`**
  - 눈 컨디션은 하루 100점에서 시작해, 관측된 시청 시간 동안 요인별로 분당 감점됩니다.
  - 감점 요인은 8가지입니다: 화면 시청, 가까이 보기, 어두운 곳, 번쩍이는 화면, 오래 보기, 깜빡임 감소, 찡그림·감김, 누워서 보기.
  - 어두운 곳에서 보면 시간에 따라 감점이 최대 ×3까지 커지고, 화면 종류(정적 ×0.6 / 보통 ×1.0 / 자극적 ×1.6)와 밝기 설정에 따라서도 달라집니다.
  - 가까이 보기는 35cm 절대 기준과 평소 거리(지난 7일 평균) 중 더 엄한 쪽으로 판단합니다.
  - 요인이 겹치면 전체 감점에 배수를 곱합니다: 어두운 곳+가까이 ×1.3, 어두운 곳+가까이+30분 이상 ×1.6. 감점 상한은 분당 3점입니다.
- **회복**
  - 케어 중 화면을 끈 시간에는 처음 5분 분당 +1.5점, 그 뒤 분당 +1.0점이 회복됩니다.
  - 케어를 켜지 않은 사이에는 Android 사용 기록에 남은 화면 꺼짐 시간만큼 회복합니다(사용 정보 접근이 허용된 경우).
  - 확인되지 않은 시간은 휴식으로 치지 않습니다.
- **알림 7종**: 위험 / 주의 / 예고("이대로면 N분 뒤") / 휴식 시간 / 어두운 곳+자극적 화면 / 너무 가까움 / 보통 진입
  - 휴식 간격은 위험할수록 짧아집니다: 20분 → 15분(어두움 또는 가까이) → 10분(둘 다) → 7분(둘 다 + 자극적 화면).
- **알림 전달 방식**
  - 이전에는 '다른 앱 위 카드' 설정을 켜야만 휴식 알림이 왔습니다. 이제는 꺼져 있어도 일반 알림으로 옵니다.
  - 알림 버튼은 "10분 뒤에"와 "이번 케어 알림 끄기"입니다.
- **화면 변경**
  - 측정 중: '지금 감점 요인'(분당 감점, 요인별 막대, 위험 조합 표시, 예고, 다음 휴식 알림까지 남은 시간)
  - 홈·리포트: '오늘 감점된 이유'(요인별 누적 감점과 개선 팁)
  - 설정: 알림 규칙 설명
- **기록**
  - 리포트 `score`에는 오늘 누적 감점을 저장하고, `contributions`에는 요인별 감점을 저장합니다.
  - 새 신호 K01–K10을 추가했습니다. 이전 산식의 영역 점수도 계속 함께 저장합니다.
