# 0.7.3 지표 검토

이번 버전의 새 지표는 **보고서별 주관적 눈 피로도 0–10 응답**이다. 수정은 별도 불변 이벤트로 남기고, 원래 관측 점수와 구별한다. 같은 산식 버전의 이전 유효 응답이 5개 이상일 때만 중앙값 차이를 축소하고 ±12점으로 제한한 개인 참고 점수를 표시한다. 이 값은 진단 또는 검증된 예측치가 아니다.

추가 카메라 지표도 검토했다. 화면 작업 중 깜박임 빈도와 불완전 깜박임의 의미는 문헌에 있지만, 앱은 이미 F02 깜박임/분, F03 최장 간격, F05 불완전 비율, F07 눈감김 비율, F08 긴 눈감김과 거리 노출을 측정·점수화한다. 같은 현상을 다른 이름으로 다시 가중하면 증거를 중복 계산한다. 특히 표준화된 환경의 자동 깜박임 정량화 연구도 외부 임상 검증이 더 필요하다고 명시한다. 따라서 0.7.3에서 새 카메라 가중치를 추가하지 않고, 주관적 응답과 관측 품질의 실제 짝 자료를 모아 다음 산식 버전에서 후보별 추가 설명력을 평가한다.
