# 0.13.0-alpha: EYE·休 리디자인, 5단계 컨디션, 평균 거리 안내, 저조도 측정

## 1. 앱 이름과 브랜드

- 앱 이름은 **EYE·休**입니다(`res/values/strings.xml`).
- 런처 아이콘을 새로 만들었습니다. 숲색 배경 위에 흰 눈과 잎 모양을 얹은 적응형 아이콘이고, Android 13 이상의 테마 아이콘(monochrome)도 지원합니다.
- 패키지 ID `com.neurolens.eyecare`와 서명은 그대로입니다. 기존 앱 위에 덮어써서 설치되고 기록도 유지됩니다.

## 2. 디자인 시스템 (`ui/theme`, `ui/components`)

- **색 (라이트)**
  - 배경: 따뜻한 리넨 `#F6F5F0`
  - 카드: 흰색
  - 주 색: 숲색 `#1F6F5C`
  - 본문: `#15211E`, 보조 글자: `#55655F`
- **색 (다크)**: 깊은 숲색 배경 `#0D1513`. 시스템 설정을 따라가며, 밤에 쓰는 일이 많은 앱이라 다크 테마도 함께 설계했습니다.
- **5단계 색**: 위험 `#E35D52` · 주의 `#F08F43` · 보통 `#F0BE45` · 양호 `#7DC069` · 매우 양호 `#2FA57F`
  - 단계마다 채움색, 글자색, 연한 배경색을 따로 둡니다.
  - 글자색은 카드 배경 대비 4.5:1 이상입니다.
  - 색만으로 단계를 구분하지 않도록 항상 단계 이름을 함께 표시합니다.
- **글꼴**: Pretendard(SIL OFL 1.1)를 Regular/Medium/SemiBold/Bold로 넣었습니다(약 6.3MB). 라이선스는 `res/raw`에 두고 설정 → 오픈소스 라이선스에서 볼 수 있습니다.
  - 본문은 14sp 이상으로 했습니다.
  - Android는 한글을 음절 단위로 줄바꿈합니다. `keepAll()`로 낱말 안에 줄바꿈 방지 문자(보이지 않는 U+2060)를 넣어, 띄어쓰기에서만 줄이 바뀌게 했습니다.
- **모양**
  - 카드 모서리 26dp, 타일 22dp
  - 버튼은 알약 모양이고 높이 56dp(주 버튼), 48dp(보조 버튼)
  - 터치 영역은 48dp 이상입니다.
- **아이콘**: 24dp 격자의 선 아이콘(획 1.8) 17종을 직접 그려 한 가지 스타일로 맞췄습니다(`EyeIcons`).
- **구성 요소**: 컨디션 링 게이지(처음 표시될 때 채워지는 애니메이션), 5단계 스케일 바, 벤토 타일, 7일 막대, 선택 버튼 묶음, 목록 행, 피로 응답 선택(0~10, 두 줄)

## 3. 화면

- **홈 대시보드**
  - 맨 위에 지금 내 눈 컨디션: 링 점수, 단계 칩, 한 줄 안내, 5단계 스케일
  - 그 아래 눈 케어 시작 버튼, "지금 눈은 어떤가요?"
  - 오늘의 눈 습관 타일: 화면 사용, 평균 보는 거리, 주변 밝기, 눈 깜빡임
  - 거리 안내 카드, 최근 7일 막대
- **측정 중**: 진행 시간, 다음 리포트까지 남은 시간, 지금 컨디션, 지금 거리(몇 cm 더 멀리), 주변 밝기, 저조도·얼굴 위치 안내, 20초 쉬기, 케어 종료, 거리 맞추기
- **기록**
  - 눈 컨디션 흐름 차트(5단계 배경)
  - 보는 거리 흐름 차트(35cm 점선)
  - 날짜별 리포트 목록
- **리포트 상세**: 점수 링, 영향을 준 요인(높음/보통/낮음 막대), 측정 요약 타일, "이렇게 해 보세요" 팁, 피로 응답
  - 측정을 마치면 기술 화면 대신 그 세션의 최신 리포트가 바로 열립니다.
- **휴식**: 숨쉬기 원 애니메이션과 함께 20초 쉬기(이전 60초)
- **설정**: 리포트 주기, 휴식 알림, 권한, 내 데이터(CSV/JSON/공유, 웹 대시보드·자동 백업), 앱 정보, 기록 지우기
- 시스템 뒤로 가기는 상세 → 목록 → 홈 순서로 돌아갑니다. 이전에는 상세 화면에서 앱이 닫혔습니다.

## 4. 개발자·연구 흔적 정리

- 화면에서 엔진 버전, 산식, 결측·커버리지 용어, 원시 신호 목록, 세션 진단, 보정 검증 지표를 모두 뺐습니다.
- 이 정보들은 **개발자 모드**로 옮겼습니다. 설정 → 버전을 7번 누르면 켜고 끕니다.
- 알림, 휴식 카드, 측정 안내 문구는 사용자 말투로 바꿨습니다.
  - 예: "연구용 참고 알림입니다" → "20초만 먼 곳을 바라봐 주세요"
- 연구 업로드는 사용자에게 "웹 대시보드 · 자동 백업"으로 보입니다.
  - 무엇을 보내고 무엇을 보내지 않는지, 서버 기록은 지워지지 않는다는 점은 화면과 끄기 확인 창에 그대로 남겼습니다.
  - 서버 스키마, 동의·철회 흐름, 업로드 내용은 바꾸지 않았습니다.

## 5. 점수 5단계

| 눈 컨디션 | 단계 |
|---:|---|
| 80–100 | 매우 양호 |
| 60–79 | 양호 |
| 40–59 | 보통 |
| 20–39 | 주의 |
| 0–19 | 위험 |

- 경계는 읽기 쉽게 20점 단위로 나눈 표시 구간이고, 의학적 기준이 아닙니다.
- 일부만 측정된 리포트는 계속 회색 "측정 부족"으로 표시합니다.
- 휴식 알림 기준은 그대로입니다(저장 부담 ≥50, 즉 컨디션 ≤50 → '보통'의 아래쪽 절반).
- 저장값, 내보내기, 업로드는 기존 부담 점수입니다.

## 6. 평균 보는 거리와 안내 (`DailyDistance`, `DistanceGuide`)

- 평균 거리는 리포트마다 측정한 대표 거리를 유효 측정 분으로 가중 평균한 값입니다. 오늘 값이 있으면 오늘, 없으면 최근 7일 값을 씁니다.
- 앱 기준 권장 거리는 **35cm 이상**입니다(의학 기준 아님).
  - 25~35cm: "조금 가까워요 · N cm 더 멀리"
  - 25cm 미만: "너무 가까워요"
  - 측정 중에는 실시간 거리로 같은 안내를 보여 줍니다.

## 7. 저조도 측정·데이터 안정화

- 자세한 내용은 [CAPTURE_LOWLIGHT_0.13.md](CAPTURE_LOWLIGHT_0.13.md)에 있습니다.
- **카메라 쪽**: fps 범위를 하한 15 이상으로 고르고, 노출 보정을 자동 조정합니다. 어두운 프레임은 밝기를 디지털로 보정하고, 얼굴 검출 임계값을 0.4로 낮췄습니다.
- **처리 쪽**: YUV 변환을 빠르게 했고, 프레임 시각에 센서 타임스탬프를 씁니다.

- 측정 중 화면에 지금 주변 밝기를 보여 줍니다(`LiveSession.lux`).
