# EyeCare 0.3.1 실기기 검증 항목

상태: **미수행**. 컴파일·단위 테스트·lint 결과만 확인했습니다. 아래 결과란은 실제 휴대폰에서 실행한 뒤 채웁니다.

## 설치와 기본 동작

- `artifacts/eyecare-0.3.1-alpha-debug.apk`를 기존 앱 위에 설치해 DB 버전 3→4 기록이 유지되는지 확인합니다. 기존 0.3.0 테스트가 끝난 뒤 업그레이드합니다.
- 카메라 권한을 허용하고 전체 화면 공유를 시작합니다. 앱의 활성 화면에 `전면 카메라 · 관측 중`과 처리 프레임이 증가하는지 확인합니다.
- 카메라 권한을 거부해도 화면 분석과 리포트가 계속되는지 확인합니다.

## 눈 관측과 품질

- 정면에서 얼굴이 보일 때 `눈 형태 유효`와 `홍채 위치 유효` 프레임이 증가하는지 확인합니다. 눈을 감거나 얼굴을 화면 밖으로 옮겼을 때 홍채 유효 프레임의 증가가 멈추는지 확인합니다.
- 10초 이상 정면을 보거나 좌우로 눈을 움직이며 `상대 시선 안정성` 상태 변화를 관찰합니다. 이 값은 카메라 영상에서 본 홍채의 **눈 안 상대 위치**이며 화면의 정확한 응시점을 뜻하지 않습니다.
- 10분 리포트를 생성해 눈 검출 비율, 처리 FPS, 평균 개방도, 상대 움직임 상태를 확인합니다. 검출 비율의 분모는 **실제로 처리한 카메라 프레임**이므로 화면 켜짐 시간 대비 커버리지는 아닙니다.
- 케어 종료 후 `눈·시선 원자료 CSV.gz 저장`으로 파일을 저장하고 `status`, `openA/B`, `uA/vA`, `uB/vB`, `landmarks`, `blendshapes`, `headMatrix` 열과 행 수를 확인합니다. 얼굴 이미지 자체는 저장하지 않습니다.

## 연속 운영

- 다른 앱으로 이동한 상태에서 카메라와 화면 관측이 지속되는지 확인합니다.
- 화면을 끈 후 카메라 상태가 일시 정지로 바뀌고, 켠 뒤 다시 관측 중이 되는지 확인합니다.
- 화면 공유를 중지한 뒤 카메라가 계속 관측하는지, 앱에서 화면 공유를 다시 시작할 수 있는지 확인합니다.
- 다른 앱이 카메라를 사용할 때 오류 상태가 보이고, 사용이 끝난 후 재획득되는지 확인합니다.
- 30분 이상 실행하면서 실제 처리 FPS, 배터리 감소, 발열, 앱 데이터 증가량을 기록합니다. PRD의 30fps·20MB/시간 목표는 기기 측정 전이며 이 버전에서 보장하지 않습니다.
